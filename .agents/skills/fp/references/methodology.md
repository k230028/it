# 정통법 기능점수 분류 기준

이 문서는 기능 식별과 복잡도 판단에 필요한 기준만 설명한다. 실제 점수와 비용은 항상 `FP/lib/fp-rules.mjs`와 `FP/lib/config.mjs`에서 읽는다.

## 용어

| 용어 | 판단 기준 |
| --- | --- |
| DET | 사용자가 인식하고 입력·출력하거나 시스템 경계를 통과하는 고유 데이터 요소 |
| RET | ILF·EIF 안에서 사용자가 인식하는 논리적 하위 레코드 그룹 |
| FTR | 트랜잭션이 읽거나 유지하는 ILF·EIF |
| ILF | 애플리케이션 경계 안에서 유지되는 논리 데이터 그룹 |
| EIF | 다른 애플리케이션이 유지하고 이 애플리케이션은 읽기만 하는 논리 데이터 그룹 |
| EI | 외부 입력으로 ILF를 유지하거나 시스템 상태를 변경하는 프로세스 |
| EO | 계산·파생·집계·형식 변환을 포함해 경계 밖으로 데이터를 내보내는 프로세스 |
| EQ | 파생 계산 없이 데이터를 조회해 반환하는 프로세스 |

## 데이터 기능 복잡도

| RET \ DET | 1~19 | 20~50 | 51 이상 |
| --- | --- | --- | --- |
| 1 | Low | Low | Average |
| 2~5 | Low | Average | High |
| 6 이상 | Average | High | High |

## EI 복잡도

| FTR \ DET | 1~4 | 5~15 | 16 이상 |
| --- | --- | --- | --- |
| 0~1 | Low | Low | Average |
| 2 | Low | Average | High |
| 3 이상 | Average | High | High |

## EO·EQ 복잡도

| FTR \ DET | 1~5 | 6~19 | 20 이상 |
| --- | --- | --- | --- |
| 0~1 | Low | Low | Average |
| 2~3 | Low | Average | High |
| 4 이상 | Average | High | High |

## 실무 판정

- 라벨, 장식 아이콘, 페이징 UI 자체는 DET로 세지 않는다.
- 저장·조회 버튼은 데이터 필드가 아니지만 경계를 넘는 제어 정보가 독립적으로 인식되면 DET 후보가 된다.
- 합계·평균·비율·그래프처럼 파생 결과를 만들면 EO, 저장값을 그대로 조회하면 EQ로 본다.
- 외부 REST API 데이터는 다른 애플리케이션이 유지하고 참조만 하면 EIF 후보다.
- 여러 물리 테이블이 하나의 사용자 인식 논리 그룹이면 하나의 ILF가 될 수 있다.
- 감사·로그·이력 테이블은 사용자가 인식하고 업무 기능으로 유지·조회하는지 확인한 뒤 분류한다.

경계나 분류가 불명확한 항목은 가정을 기록하고 별도 검토 대상으로 남긴다.
