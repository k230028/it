
## 5.6 회의내용 반영

### 개요
예산현황, 전산업무비 목록, 정보기술부문 계획 화면에 대상 수정 요구사항 반영

#### 예산현황
1. /budget/status 예산현황 2025년(세부 비목), 2026년(세부 비목) 제거 > 금액만 있으면 됨 (전산업무비는 항상 비목 1개)
2. /budget/status 예산현황 마지막 컬럼에 [증감] 컬럼 추가
3. /budget/status [정보화사업] 등 내보내기 시 '사업개요' 컬럼은 HTML 태그가 없는 Plain Text 형태로 나오도록 개선

#### 전산업무비
4. /info/cost 전산업무비 목록에서 [예산(전년도)] 컬럼을 추가해서 PUl_DTT가 '계속(PUl_DTT_002)' 사업인 경우 금액이 표기되도록 개선
5. /info/cost 전산업무비 목록에서 0건인 상태에서 [수정] 버튼을 눌렀을 때 전년도 전산업무비 목록 팝업을 보여주고 선택해서 넣을 수 있도록 개선
6. /info/cost 전산업무비 목록에서 '편집모드'인 경우 [전년도 목록 불러오기] 버튼을 추가해서 5번과 동일한 팝업을 보여주도록 개선
7. /info/cost 전산업무비 목록에서 [저장] 시 '예산', '비목코드', '지급주기'가 동일한 경우 사용자가에 동일한 내용을 작성한게 아닌지 확인하는 팝업을 띄우도록 개선

#### 정보기술부문 계획 
8. /info/plan, /info/plan/form 2개 화면 관리자 권한 보유자만 접속 가능하도록 개선 (공통 왕관 아이콘 추가)
9. /info/plan/form [저장] 시 '전산예산, 자본예산, 일반관리비 등' 모든 정보가 저장되도록 개선
