
## *info/cost (전산업무비 목록)*

1. *'계속' 사업에서 전년도 예산을 가져올 때 통화가 '외화'인 경우 외화금액을 가져오도록 수정*

2. *기본 정렬을 아래의 기준으로 조정*
 - *1순위 : '신규/계속' 컬럼 기준 ('신규' > '계속')*
 - *2순위 : 최근 수정일 (내림차순)*


## *info/cost/[id] (전산업무비 상세)*

*'연관사업' 클릭 시 '신규 탭'이 아닌 '다이얼로그' 형태로 보이도록 수정해줘*


## *TerminalTableSection.vue (금융정보단말기 다이얼로그)*

1. *금융정보단말기 '다이얼로그'에서 수정 후 '저장' 시 ? 아이콘 상단이 살짝 잘리는 문제 해결하고 '취소' 버튼 디자인을 info/cost 수정 화면의 '취소' 버튼 스타일과 일치시켜줘*
2. *금액 컬럼에 표기되는 원화환산 표시 제거해줘 (해당 div 때문에 컬럼 높이가 어색하게 늘어나는 문제 해결)*


## *TerminalTableSection.vue (금융정보단말기 다이얼로그)*

1. *금액 수정 시 '총 금액'에 즉시 반영되어 보이도록 해줘*
2. *통화 컬럼을 금액 컬럼 앞에 배치해줘*


## TerminalTableSection.vue (금융정보단말기 다이얼로그)

기본적으로 '조회/편집' 라디오 버튼을 숨기고 화면 성격별로 관련된 모드로 보여주도록 해줘

- info/cost/form?id=, info/cost '수정' 화면에서 클릭 시 등 수정 화면 : '편집' 모드
- info/cost/[id], info/cost '조회' 화면에서 클릭 시  등 조회 화면 : '조회' 모드

그리고,  info/cost '수정' 화면에서 '금융정보단말기' 수정 후 다이얼로그에서는 '저장' 버튼을 없애주고 info/cost '수정' 화면에서 '저장' 클릭 시 저장되도록 해줘
