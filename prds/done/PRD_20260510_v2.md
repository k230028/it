# 신규 기능 설계
## 1. 게시판
본 프로젝트에서 공통적인 목적으로 사용 가능한 게시판 기능 설계 및 구현
### ㅇ 메뉴
- TOP 메뉴 : 게시판
- Sidebar 메뉴
 1) 공지사항
 2) 자료실
### ㅇ 주요 기능
- 게시글 작성, 수정, 삭제
- 게시글 답변글 작성
- 파일첨부 (프로젝트 공통 첨부파일 관리 기능 사용)
- 웹에디터 (프로젝트 공통 웹에디터 사용 - TIPTAP)
- 게시글 공개 시작-종료 기간 설정
### ㅇ 스키마(안)
테이블명 : TAAABB_CBORDM (게시판)
