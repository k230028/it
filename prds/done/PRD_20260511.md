# ~~공통코드 체계 개선~~
~~코드는 특정 컬럼(엔티티) 이름(CUR, PRJ_TP 등)에 해당하는 값을 의미하고, 해당 컬럼(엔티티)에 값으로 존재할 수 있는 유형을 코드값 001, 002...으로 나열하는 것으로 변경~~

- ~~코드(코드ID) : 컬럼(엔티티)  ex) CUR, PRJ_TP 등~~
- ~~코드값 : 코드 내 식별자  ex) 001, 002...~~
- ~~코드명 : '코드+코드값'이 의미하는 것  ex) 1400, 신규 등~~
- ~~코드설명 : 컬럼(엔티티)에 대한 설명  ex) 환율, 사업유형 등~~
- ~~코드타입 : 동일 '코드+코드값' 안에서 구분이 필요한 경우  ex) 01, 02~~
- ~~코드타입설명 : 코드타입에 대한 설명  ex) 개발비(일반), 개발비(감리/컨설팅)~~
- ~~상위코드 : 상위 코드ID  ex) 전산여비 > 국내출장~~
## ~~1. 기본키 변경~~
- ~~(전) {C_ID}+{STT_DT}~~
- ~~(후) {C_ID}+{CDVA}+{STT_DT}~~

 - ~~(후) CUR~~

~~CDVA : 원래 C_ID 값의 Postfix만 남김~~
 - ~~(전) 1400~~
 - ~~(후) 001~~

~~C_NM : 기존 CDVA~~
 - ~~(전) USD~~
