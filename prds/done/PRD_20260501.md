
## 전산업무비 화면 개선

### 개요
전산업무비 단건 조회 및 수정 화면을 정보화사업과 유사한 형태로 개편
(기존 /info/cost/ 전산업무비 일괄 조회 및 수정 화면은 유지)

- 전산업무비 단건 조회 : /info/cost/COST_2026_0004
- 전산업무비 단건 수정 : /info/cost/form?id=COST_2026_0004

### 세부사항
1. [전산업무비 단건 조회] 시 전산업무비 유형(IT_MNGC_TP)가 IT_MNGC_TP_001인 경우 화면 하단에 [금융정보단말기 상세목록] 추가 (참고 화면 : /info/projects/PRJ-2026-0012의 [소요자원 상세내용])
2. [전산업무비 단건 조회] 시 화면에 추진구분(PUL_DTT), 지급주기(DFR_CLE)를 공통코드 기준으로 코드명(C_NM)이 출력되도록 개선
3. [전산업무비 단건 수정] 화면을 정보화사업 화면처럼 Form 기반으로 변경하고 전산업무비 유형(IT_MNGC_TP)이 IT_MNGC_TP_001인 경우  [금융정보단말기 상세목록] 입력을 위한 테이블 추가 (참고 화면 : /info/projects/form?id=PRJ-2026-0012)
