# 정보화사업, 경상예산, 전산업무비 결재 완료 후 재신청 기능

1. 결재가 완료된 정보화사업, 경상예산, 전산업무비에 대해 [수정 후 재신청] 버튼을 만들어서 작성부서에서 수정 후 재신청 할 수 있도록 한다.
2. [수정 후 재신청] 사업관리번호, 예산번호는 부모 값을 그대로 사용하고 SNO+1 한다.
3. 재작성한 정보화사업, 경상예산, 전산업무비는 결재를 올릴 수 있도록 하고 결재 완료 시 최종 여부(LST_YN)을 'Y'로 세팅하고 이전 버전은 'N'으로 설정한다.
4. 정보화사업, 경상예산, 전산업무비 상세 화면에서 사업명 우측에 '이력 아이콘'을 추가해서 클릭 시 이력 목록을 다이얼로그로 보여주고 선택하여 상세 내용도 들어가볼 수 있도록 한다.
5. 이후 예산 작업 등 모든 화면에서는 최종 여부(LST_YN)가 'Y' 사업을 기준으로 활용한다.

# 타 부서 예산(정보화사업, 경상예산, 전산업무비) 상세 화면 조회 차단

1. 현재 주요 목록 화면에서는 본인 소속부서의 예산만 조회가 가능하다.
2. 타 부서 예산 상세화면(info/projects/[id], info/cost/[id]) 경로를 직접 입력하더라도 권한을 체크하여 조회가 불가능하도록 한다.
3. 예산 상세화면 조회가 가능한 사람은 (1) 동일부서 직원(부서코드 기준), (2) IT조직(부서코드 : 013, 180, 181, 182, 183, 185), (3) 시스템관리자로 제한한다.

# 사업/예산(info) 화면 [정보화사업] Card 개선

1. IT조직(013, 180, 181, 182, 183, 185)은 모두 [부서 | 전체] 버튼 조회가 가능하도록 한다.
2. 확대 보기 아이콘을 만들어서 선택 시 전체 화면으로 더 많은 정보가 보이도록 한다. (사업명, 주관부서명, IT담당부서, 총 소요금액, 당해 요청예산, 자본예산 합계, 일반관리비 합계)
3. [Excel] 버튼을 추가해서 상세 정보를 내려받을 수 있도록 한다. (사업명, 시작일, 종료일, 주관부서명, 주관부서 담당팀장, 주관부서 담당자, IT담당부서, IT담당팀장, IT담당자, 총 소요금액, 당해 요청예산, 개발비, 기계장치, 기타무형자산, 자본예산 합계, 일반관리비 합계, 전결권)
4. [IT 담당부서] 체크박스를 만들어서 체크 시 우리 부서가 IT 담당부서로 들어간 사업만 필터하여 볼 수 있도록 한다.
