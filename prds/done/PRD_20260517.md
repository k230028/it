
### Tiptap Editor 변수 입력 기능 추가

- Tiptap Editor 작성 시 `{2026.requestAmount}`와 같은 방식으로 변수값을 입력받는 기능 추가
- `{` 입력 시 드롭다운(autocomplete) 을 통해 입력 가능한 변수 목록 중 선택
- 변수 기반으로 입력된 내용은 실제 해당 값이 변하는 경우 반영되도록 구성

### 필요한 변수 목록
연도별 전산예산 편성요청액(합계)
연도별 전산예산 편성액(합계)
연도별 전산예산 편성률(총액 기준)
연도별 자본예산 편성요청액(합계)
연도별 자본예산 편성액(합계)
연도별 자본예산 편성률(총액 기준)
연도별 일반관리비 편성요청액(합계)
연도별 일반관리비 편성액(합계)
연도별 일반관리비 편성률(총액 기준)
연도별 사업별 편성요청액
연도별 사업별 편성액
연도별 사업별 편성률

### 동작방식(안)
1) tiptap 로드 시 API 요청 (ex. api/tiptapVariables)
2) `{`입력 시 드롭다운 표시 (ex. '2026 전산예산 편성요청액 900억원' 등)
3) 선택 시 변수값 입력 `{2026.requestAmount}` 화면 출력은 `900억원`
4) 게시글 수정을 하지 않더라도 동적으로 값 변경 시 반영
