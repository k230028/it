
# 정보기술부문 계획 (/info/plan/form) 
계획 [생성] 시 요약 문구를 자동으로 입력해주는 기능 추가

## 1. 정보화사업 카드 > IT프로젝트내용
H3 스타일(###)로 가장 사업금액이 큰 2개 사업 나열

- 예시
```
## 글로벌 표준 뱅킹시스템 점포별 적용, Paper-Less 시스템 개발 착수 등 당행 경쟁력 강화를 위한 핵심 사업에 IT·AI 역량 집중
```

## 2. 전산예산 카드 > IT예산내용
H3 스타일(###)로 자본예산, 일반관리비 각각 편성금액과 편성 비율, 그리고 총 편성액을 기재하고, H4 스타일(####)로 전년대비 증가요인 사업을 3개 기재(사업금액 Top2, 계속 사업 중 증가액 Top1)

- 예시
```
## 자본예산은 500억원 편성(요청예산의 80% 반영)하고, 일반관리비는 1,000억원 편성(요청예산의 100% 반영)하여 1,500억원을 편성
### (전년대비 주요 증가 요인) 글로벌 표준뱅킹시스템 재구축 +10억원, Paper-Less 구축 +20억원, 정보시스템 외주운영 +30억원 등
```
