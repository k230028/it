가정 및 주의사항

  1. 보정계수는 대표 가정값 — 실제 산정은 사업 특성별 보정계수표로 교체 필요. FP당 단가 600,000원은 보정 전 개발원가 기준 지정값.
  2. 이윤·부가세는 CONFIG 설정값(이윤 20% + 부가세 10%)을 따름. 공공사업 정식 산정은 직접경비 별도 + 이윤율(개발원가+직접경비의 25% 이내) 규정이 다를 수 있음.
  3. DET/FTR은 엔티티·DTO 필드 기반 추정 — 일부 대형 응답 DTO는 사용자 인식 항목 기준으로 보수적 평가. 화면 요건 확정 시 ±5% 내외 변동 가능.
  4. EIF 판정(4건) — 사용자/조직/자격등급을 SSO/eHR 외부 원천으로 보아 EIF 처리. 본 시스템이 직접 유지관리하는 것으로 본다면 ILF로 재분류(+8 FP).
  5. 개발 전용 API 포함 — DevAuthController 등 개발 전용 엔드포인트도 산정에 포함. 운영 범위에서 제외 시 해당 행 차감.
  6. 변경로그(*L) 38종 중 엔티티가 매핑된 38종은 별도 ILF가 아닌 마스터 논리파일의 RET(+1)로 처리하여 중복 계상 회피.
  7. 화면 79개는 규모 참고 지표 — FP 산정의 계상 단위가 아님(단위 프로세스 기준 산정).
