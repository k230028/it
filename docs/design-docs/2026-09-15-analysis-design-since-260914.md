#### 3. 개발 방향 설계

##### 가. 요건별 설계 방향

- **요건 1. IT담당부서 직원검색 기본 범위 '전체'**

| 구분             | 내용                                                                                                                                                                                |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **현행**   | 직원검색 다이얼로그 검색범위가 항상 '부서'로 시작 · IT담당부서 지정 때마다 '전체' 전환 필요                                                                                        |
| **변경**   | 다이얼로그에 기본 검색범위 prop 추가 · 열기 함수에 초기 범위 인자 추가 · 정보화사업 폼 IT담당부서 검색만 '전체' 전달                                                              |
| **영향도** | 다른 호출 화면(`/budget/report`, `/info/cost/form`, `/info/cost`, `/info/council-request`, `/info/projects/report`, 결재선 편집)은 기본값 '부서' 유지 · 백엔드 변경 없음 |

- **요건 2. 예산 목록 연도 선택 첫 방문 안내**

| 구분             | 내용                                                                                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **현행**   | 제목의 연도 버튼이 클릭 가능함을 알리는 장치 없음 · 첫 방문자가 연도 변경 방법을 찾지 못함                                                   |
| **변경**   | 첫 방문 안내 composable 신설(localStorage 닫기 기록, 저장소 실패 시 메모리 동작) · 연도 제목 컴포넌트에 강조 링·`role=status` 말풍선 추가 |
| **영향도** | `/budget/list` 한정 · 같은 컴포넌트를 쓰는 `/info/cost`, `/info/projects`, `/budget/*`는 hint 미지정 시 변화 없음                    |

- **요건 3. 전산업무비 전년도 예산 통화 표시**

| 구분             | 내용                                                                                                                                                                           |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **현행**   | 전년도 예산을 외화 행은 외화금액·원화 행은 원화로 합산해 금액만 응답 · 화면은 항상 원화로 표기해 외화 행 대조가 어긋남                                                       |
| **변경**   | 합산 메서드 제거 · 전년도`LST_YN='Y'` 원장을 IN 배치 조회해 `prevBgAmt`·`prevCurC` 응답 · 화면은 행 통화로 표기 · 전년도 불러오기도 통화 복제 · OpenAPI 타입 재생성 |
| **영향도** | `GET /api/costs` 응답 필드 추가(하위 호환) · 목록·상세·불러오기 화면 · OpenAPI 계약 테스트 필수 필드 갱신                                                                |

- **요건 4. 결재 상신 담당부서 필터(관리자)**
