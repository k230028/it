# FE-94 일반 사용자 행번 비표시 분석·설계

- 요청자 K230028, 요청일 2026-09-21.
- 이름(행번)은 이름만 표시. 행번 열을 제거. 이름이 없는 직원은 빈칸으로 표시.
- 관리자 전용 페이지의 기존 표시는 유지. 로그인 계정의 역할이 아니라 현재 화면 경로로 공통 컴포넌트 표시 정책을 판정.
- /admin/**, /info/plan/**, /info/council-request/prepare/**의 행번 표시는 유지. 협의회 관리자 전용 컴포넌트는 변경하지 않음.
- 업무 화면의 헤더, 직원 정보·검색·자동완성, 사업/비용 작성·상세, 결재선, 동시 수정 충돌 비교, 사전협의 등록자·수정자, 공통 직원 링크에 적용.
- 일반 조회용 사업·비용·단말 Excel 및 예산 PDF의 행번을 제외. 다운로드 행 객체와 헤더에서 모두 제거.
- 이름 없는 사전협의 수정자는 빈칸(API에 수정자 이름 없음). 사업 충돌 payload에는 이름이 없어 직원 식별자 비교값은 빈칸. 선택 라벨(내 수정/상대 수정)과 실제 병합값은 유지.
- 내부 ENO·USID·CGPR_ID 및 결재선 id는 그대로 유지. 직원 선택 emit/API 요청·결재·연락 기능은 동일한 식별자를 사용.
- 사번 자리에 실제 이름이 저장된 레거시 데이터는 식별자 형식 검사 후 이름 텍스트만 유지.
- 입력용 엑셀 양식/기존 파일의 사번 해석은 그대로 유지(값을 자동 출력하지 않음). 사용자 지시로 전산업무비 업로드 양식의 담당자사번 열 및 기존 입력·처리 방식을 유지하기로 확정.
- 수동 로그인 행번 입력은 인증에 필요한 입력이므로 기존 기능 유지.

## 검증

- 관리자 경로와 일반 경로를 구분하고, 공통 헤더가 유지된 채 경로가 바뀌어도 표시 정책이 갱신되는지 검사.
- 이름 누락·이름(행번)·직원 선택 내부 식별자 보존·다운로드 행번 열 제거·PDF 이름 누락 검증.
- Playwright: 정보화사업/전산업무비 작성 화면의 담당자와 헤더, 직원 정보 다이얼로그의 행번 비표시 2건 통과.
- npm run check 통과(기존 경고만 존재). 전체 회귀 검사 결과는 테스트 결과서에 기록.
