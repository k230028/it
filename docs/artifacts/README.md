# docs/artifacts

Artifact(claude.ai 게시 웹 페이지)로 발행하는 산출물의 **원본 소스**를 보관합니다.
게시된 페이지는 이 디렉터리의 파일을 그대로 렌더한 것이므로, 내용을 고칠 때는
게시본이 아니라 여기 있는 파일을 고친 뒤 재발행합니다.

## 파일

| 파일 | 내용 | 게시 URL |
| --- | --- | --- |
| `task-ledger.html` | `TASK.md` 활성 잔여과제 + `TASK_DONE.md` 완료 이력 대시보드 | https://claude.ai/code/artifact/538e83b3-c0c8-4e1c-8619-aefc4d61c427 |

## 갱신 절차

1. 이 디렉터리의 HTML을 수정합니다. 데이터는 파일 안의
   `<script type="application/json" id="data">` 블록에 인라인으로 들어 있습니다
   (외부 요청이 CSP로 차단되므로 페이지는 반드시 자기완결적이어야 합니다).
2. 로컬 확인이 필요하면 정적 서버로 열어 봅니다 — `file://`는 도구가 차단합니다.
3. **같은 URL을 유지하려면** 재발행 시 위 표의 URL을 `url` 인자로 넘깁니다.
   URL 없이 발행하면 별도 아티팩트가 새로 만들어집니다.

## 유지보수 시 주의

- **단일 진실 공급원은 `TASK.md`·`TASK_DONE.md`입니다.** 이 페이지는 특정 시점의
  읽기 전용 사본이며 자동 갱신되지 않습니다. 과제를 추가·완료 처리할 때는 원본
  마크다운을 고치고, 이 페이지는 필요할 때 다시 옮깁니다. 페이지 상단의 기준일을
  함께 갱신하세요.
- **과제 ID는 영역별 일련번호라 완료 이관 뒤 재사용됩니다.** 활성 `SEC-12`(OnePass FIDO)와
  아카이브 `SEC-12`(SSO 로그 원문 제거)는 서로 다른 과제입니다. 활성/아카이브에 같은
  번호가 있는 경우는 자동 대조로 구분할 수 없으므로 JSON의 `idNotes`에 손으로
  관리합니다 — `reused`는 다른 과제, `carried`는 같은 과제가 아직 활성인 경우입니다.
  ID를 추가·이관할 때 이 맵을 함께 확인하세요.
- 완료 이력은 각 항목의 **요약만** 담았습니다. 커밋 해시·검증 증거 표는 `TASK_DONE.md` 원문에 있습니다.
