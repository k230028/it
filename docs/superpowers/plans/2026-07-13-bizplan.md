# 사업계획(Bizplan) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 정보기술부문 계획에 포함된 사업별 사업계획 문서(보고서 + 일정/품목/계약)를 작성·완료하는 기능을 신규 라우트 `/project/bizplan`에 구현한다.

**Architecture:** 백엔드는 `domain/bizplan` 신규 도메인(estimate 패턴 미러, 마스터 4 + 로그 4 테이블, `@LogTarget` 엔티티 리스너 로깅). 상태 21/29는 A안에 따라 `TPRMPP_BPROJA`에만 기록(`CNCD_RFR_NO = 'BIZ-'+사업관리번호`). 프론트는 estimate 목록/상세 화면을 미러링하고 DB 메뉴를 repoint한다.

**Tech Stack:** Spring Boot 4 / Java 25 / JPA+QueryDSL / Oracle(Flyway), Nuxt 4 / PrimeVue / Tailwind / Tiptap

**스펙:** `docs/superpowers/specs/2026-07-13-bizplan-design.md`

**스펙 정정 1건 (Task 10에서 문서 반영):** 스펙 §3.4의 자식 행 "신규 행은 서버가 MAX+1 채번"을 **"SNO는 프론트가 부여(기존 행 유지, 신규 = 현재 최대+1), 서버는 (ABUS_MNG_NO, SNO) 기준 upsert + 요청에 없는 활성 행 soft delete"**로 정정한다. 이유: 품목의 `CTT_SNO`가 같은 저장 요청 안의 **신규 계약 행**을 참조할 수 있어야 하는데, 서버 채번이면 프론트가 신규 계약의 SNO를 알 수 없다. 이 방식은 estimate `saveLines`의 키 기반 upsert(삭제행 복원 포함) 패턴과 동일하다.

## 사전 지식 (모든 Task 공통)

- **멀티 레포**: `it_database`/`it_backend`/`it_frontend`는 각각 독립 git 레포다. 커밋은 반드시 `git -C <레포>`로 해당 레포의 main에 한다. 루트 `C:\it` 레포는 docs 전용.
- **로컬 DB**: `sqlplus ITPAPP/kdb1234!!@127.0.0.1:11521/XEPDB1` (dev 폴백 비밀번호). 객체 소유 스키마는 `ITPOWN`.
- **백엔드 테스트 제약**: 로컬에서 `./gradlew test`가 worker JVM 기동 단계에서 죽는 알려진 이슈가 있다. 테스트 실행이 이 증상으로 실패하면 `./gradlew compileJava compileTestJava`로 컴파일 검증을 대체하고 그 사실을 기록한다(테스트 코드는 그대로 커밋).
- **기존 상태코드 확인 완료**: 로컬 CCODEM에 `IT_PTL_STS_TC` 21='사업계획 작성중'(CO_CDVA_NM=10), 29='사업계획 작성완료'(CO_CDVA_NM=100)가 이미 존재. 마이그레이션은 MERGE(멱등)로 dev/prod까지 보장한다.
- **메뉴 실데이터 확인 완료**: `TPRMPP_CMENUM`에서 사업 목록 메뉴는 `MNU_ID='MINF0016'`, `MNU_NM='사업 목록'`, `MNU_TP_C='LNK'`, `SRE_PTH='/info/projects'`, 상위 `MINF0015`(정보화사업). `TPRMPP_CMENUD`(라우트 카탈로그)에 `/project/bizplan`은 미등록 상태.
- **백엔드 주석은 한글**, `@Column`에 comment 필수, `@RequestParam`/`@PathVariable`에 `name=` 필수.

```java
package com.kdb.it.domain.bizplan.repository;

import com.kdb.it.domain.bizplan.dto.BizplanDto;
import com.kdb.it.domain.bizplan.entity.QBbizpm;
import com.kdb.it.domain.budget.plan.entity.QBplana;
import com.kdb.it.domain.budget.project.entity.QBproja;
import com.kdb.it.domain.budget.project.entity.QBprojm;
import com.querydsl.core.BooleanBuilder;
import com.querydsl.core.types.Projections;
import com.querydsl.jpa.impl.JPAQueryFactory;
import java.util.List;
import lombok.RequiredArgsConstructor;
import org.springframework.util.StringUtils;

/**
 * 사업계획 목록 QueryDSL 구현.
 *
 * <p>BPLANA(계획-사업 관계)에 포함된 사업을 기준으로, BBIZPM(사업계획)과
 * BPROJA(상태, {@code CNCD_RFR_NO='BIZ-'+ABUS_MNG_NO})를 LEFT JOIN 한다.
 * 한 사업이 여러 연도 계획에 포함될 수 있어 {@code distinct()} 가드를 둔다.</p>
 */
@RequiredArgsConstructor
public class BizplanRepositoryImpl implements BizplanRepositoryCustom {

    /** BPROJA 사업계획 단계 키 접두사 (BizplanService와 동일 값 유지) */
    private static final String BPROJA_KEY_PREFIX = "BIZ-";

    private final JPAQueryFactory queryFactory;

    @Override
    public List<BizplanDto.ListItem> search(String bbrC) {
        QBplana pa = QBplana.bplana;
        QBprojm p = QBprojm.bprojm;
        QBbizpm bp = QBbizpm.bbizpm;
        QBproja a = QBproja.bproja;

        BooleanBuilder where = new BooleanBuilder();
        where.and(pa.delYn.eq("N"));
        // bbrC는 Bprojm.svnDpmC(주관부서코드)로 필터링 — JWT 클레임 bbrC와 동일 도메인
        if (StringUtils.hasText(bbrC)) {
            where.and(p.svnDpmC.eq(bbrC));
        }

        return queryFactory
                .select(Projections.constructor(BizplanDto.ListItem.class,
                        p.abusMngNo,   // 사업관리번호
                        p.abusNm,      // 사업명
                        p.svnDpmC,     // 주관부서코드
                        p.svnDpmNm,    // 주관부서명(스냅샷)
                        p.bseYy,       // 예산연도
                        bp.totRqmAmt,  // 총소요금액(사업계획 미생성 시 null)
                        a.stsTc,       // 사업계획 상태(21/29, 미생성 시 null=미작성)
                        bp.lstChgDtm)) // 사업계획 최종변경일시
                .distinct()
                .from(pa)
                .join(p).on(p.abusMngNo.eq(pa.prjMngNo)
                        .and(p.lstYn.eq("Y"))
                        .and(p.delYn.eq("N")))
                .leftJoin(bp).on(bp.abusMngNo.eq(p.abusMngNo).and(bp.delYn.eq("N")))
                .leftJoin(a).on(a.abusMngNo.eq(p.abusMngNo)
                        .and(a.cncdRfrNo.eq(p.abusMngNo.prepend(BPROJA_KEY_PREFIX)))
                        .and(a.delYn.eq("N")))
                .where(where)
                .orderBy(p.abusMngNo.desc())
                .fetch();
    }
}
```

```java
     *
     * <p>생성 시 사업명은 BPROJM에서 복사하고, 예산번호는 BPROJA의 예산편성 행({@code BG-%})에서
     * 자동 연계한다(없으면 null). 이미 존재하면 부수효과 없이 상세만 반환한다(멱등).</p>
     *
     * @param abusMngNo 사업관리번호
     * @param user      요청자 인증 정보

    @Transactional

        verifyDeptOrAdmin(project.getSvnDpmC(), user);

        Bbizpm plan = bizplanRepository.findByAbusMngNoAndDelYn(abusMngNo, "N").orElse(null);
        if (plan == null) {
            plan = Bbizpm.builder()
                    .abusMngNo(abusMngNo)
                    .abusNm(project.getAbusNm())
                    .bgNo(resolveBgNo(abusMngNo))
                    .build();
            bizplanRepository.save(plan);
            bprojaSyncService.upsert(abusMngNo, bprojaKey(abusMngNo), STS_IN_PROGRESS);
        }
        return toDetail(plan);
    }

     * 품목 {@code cttSno}는 요청 계약 목록의 SNO만 허용(null 가능).
     * 저장 마지막에 총소요금액을 활성 품목 금액 합계로 재계산한다.
     * 완료(29) 상태에서도 저장 가능하며 상태는 변경하지 않는다.</p>
     *
     * @throws IllegalArgumentException SNO 중복, cttSno 불일치, 사업계획 미생성
     * @throws AccessDeniedException    주관부서도 관리자도 아닌 경우
     */
    @Transactional
    public void save(String abusMngNo, BizplanDto.SaveRequest req, CustomUserDetails user) {
        Bprojm project = loadEligibleProject(abusMngNo);
        verifyDeptOrAdmin(project.getSvnDpmC(), user);
        Bbizpm plan = loadPlan(abusMngNo);

        // 보고서(Tiptap HTML)는 저장 전 서버 새니타이즈 (프론트 DOMPurify는 보조 계층, null 허용)
        String sanitized = req.redtConeInf() == null ? null : HtmlSanitizer.sanitize(req.redtConeInf());
        plan.updateBasics(sanitized, req.itPtlEdrtTc());

        // 계약 먼저 병합 — 품목 cttSno 검증에 쓸 유효 SNO 집합 확보
        Set<Integer> contractSnos = mergeContracts(abusMngNo, req.contracts());
        BigDecimal total = mergeItems(abusMngNo, req.items(), contractSnos);
        mergeSchedules(abusMngNo, req.schedules());

        plan.changeTotalAmount(total);
    }

    /**
     * 완료 처리 — BPROJA 상태 21→29 전이만 허용.
     *
     * @throws IllegalArgumentException 목표 상태가 29가 아닌 경우
     * @throws IllegalStateException    현재 상태가 21이 아닌 경우
     */
    @Transactional
    public void complete(String abusMngNo, BizplanDto.StatusRequest req, CustomUserDetails user) {
        Bprojm project = loadEligibleProject(abusMngNo);
        verifyDeptOrAdmin(project.getSvnDpmC(), user);
        loadPlan(abusMngNo);

        if (!STS_DONE.equals(req.stsTc())) {
            throw new IllegalArgumentException("사업계획은 완료(29) 전이만 허용됩니다: " + req.stsTc());
        }
        String current = currentStatus(abusMngNo);
        if (!STS_IN_PROGRESS.equals(current)) {
            throw new IllegalStateException("작성중(21) 상태에서만 완료할 수 있습니다. 현재: " + current);
        }
        bprojaSyncService.upsert(abusMngNo, bprojaKey(abusMngNo), STS_DONE);
    }

    // -------------------------------------------------------------------------
    // 내부 헬퍼
    // -------------------------------------------------------------------------

    /** BPROJA 사업계획 단계 키 조립 */
    private String bprojaKey(String abusMngNo) {
        return BPROJA_KEY_PREFIX + abusMngNo;
    }

    /** 현재 유효 사업 조회 + BPLANA 포함 검증 */
    private Bprojm loadEligibleProject(String abusMngNo) {
        Bprojm project = projectRepository.findByAbusMngNoAndLstYnAndDelYn(abusMngNo, "Y", "N")
                .orElseThrow(() -> new IllegalArgumentException("사업을 찾을 수 없습니다: " + abusMngNo));
        if (!bplanaRepository.existsByPrjMngNoAndDelYn(abusMngNo, "N")) {
            throw new IllegalArgumentException("정보기술부문 계획에 포함되지 않은 사업입니다: " + abusMngNo);
        }
        return project;
    }

    /** 사업계획 마스터 조회 (진입 이전이면 미생성 오류) */
    private Bbizpm loadPlan(String abusMngNo) {
        return bizplanRepository.findByAbusMngNoAndDelYn(abusMngNo, "N")
                .orElseThrow(() -> new IllegalArgumentException("사업계획이 아직 생성되지 않았습니다: " + abusMngNo));
    }

    /**
     * 주관부서 또는 관리자 검증.
     *
     * <p>사업계획은 부서 문서이므로 최초등록자(개인) 기준 {@code OwnershipVerifier.verifyOwnerOrAdmin}
     * 대신 부서 단위로 검증한다.</p>
     */
    private void verifyDeptOrAdmin(String svnDpmC, CustomUserDetails user) {
        if (user == null) {
            throw new AccessDeniedException("인증 정보가 없습니다.");
        }
        if (user.isAdmin()) {
            return;
        }
        if (svnDpmC != null && svnDpmC.equals(user.getBbrC())) {
            return;
        }
        throw new AccessDeniedException("사업 주관부서 또는 관리자만 수행할 수 있습니다.");
    }

    /** BPROJA 예산편성 행(BG-%)에서 예산번호 자동 연계 (없으면 null) */
    private String resolveBgNo(String abusMngNo) {
        return bprojaRepository.findByAbusMngNoAndDelYn(abusMngNo, "N").stream()
                .map(Bproja::getCncdRfrNo)
                .filter(key -> key != null && key.startsWith(BG_KEY_PREFIX))
                .findFirst()
                .orElse(null);
    }

    /** BPROJA에서 사업계획 단계 현재 상태 조회 (행이 없으면 21로 간주) */
    private String currentStatus(String abusMngNo) {
        return bprojaRepository.findById(new BprojaId(abusMngNo, bprojaKey(abusMngNo)))
                .filter(a -> !"Y".equals(a.getDelYn()))
                .map(Bproja::getStsTc)
                .orElse(STS_IN_PROGRESS);
    }

    /** 요청 행 SNO 중복 검증 */
    private static void verifyUniqueSnos(String label, List<Integer> snos) {
        Set<Integer> seen = new HashSet<>();
        for (Integer sno : snos) {
            if (!seen.add(sno)) {
                throw new IllegalArgumentException(label + " 일련번호가 중복되었습니다: " + sno);
            }
        }
    }

    /** 일정 병합 */
    private void mergeSchedules(String abusMngNo, List<BizplanDto.ScheduleRequest> rows) {
        verifyUniqueSnos("일정", rows.stream().map(BizplanDto.ScheduleRequest::sno).toList());
        Map<Integer, Bbizsm> bySno = bbizsmRepository.findByAbusMngNoOrderBySnoAsc(abusMngNo).stream()
                .collect(Collectors.toMap(Bbizsm::getSno, Function.identity()));
        Set<Integer> incoming = new HashSet<>();
        for (BizplanDto.ScheduleRequest row : rows) {
            incoming.add(row.sno());
            Bbizsm existing = bySno.get(row.sno());
            if (existing != null) {
                if ("Y".equals(existing.getDelYn())) {
                    existing.restore(); // 삭제행 재사용 시 복원 (PK 충돌 방지)
                }
                existing.updateSchedule(row.dsdCone(), row.sttDt(), row.endDt());
            } else {
                bbizsmRepository.save(Bbizsm.builder()
                        .abusMngNo(abusMngNo).sno(row.sno())
                        .dsdCone(row.dsdCone()).sttDt(row.sttDt()).endDt(row.endDt())
                        .build());
            }
        }
        softDeleteMissing(bySno.values(), Bbizsm::getSno, incoming, Bbizsm::delete);
    }

    /** 품목 병합 + cttSno 검증 + 활성 품목 금액 합계 반환 */
    private BigDecimal mergeItems(String abusMngNo, List<BizplanDto.ItemRequest> rows,
            Set<Integer> contractSnos) {
        verifyUniqueSnos("품목", rows.stream().map(BizplanDto.ItemRequest::sno).toList());
        for (BizplanDto.ItemRequest row : rows) {
            if (row.cttSno() != null && !contractSnos.contains(row.cttSno())) {
                throw new IllegalArgumentException(
                        "품목이 참조하는 계약 일련번호가 존재하지 않습니다: " + row.cttSno());
            }
        }
        Map<Integer, Bbizgm> bySno = bbizgmRepository.findByAbusMngNoOrderBySnoAsc(abusMngNo).stream()
                .collect(Collectors.toMap(Bbizgm::getSno, Function.identity()));
        Set<Integer> incoming = new HashSet<>();
        for (BizplanDto.ItemRequest row : rows) {
            incoming.add(row.sno());
            Bbizgm existing = bySno.get(row.sno());
            if (existing != null) {
                if ("Y".equals(existing.getDelYn())) {
                    existing.restore();
                }
                existing.updateItem(row.gclNm(), row.ioeC(), row.qty(), row.amt(), row.fcAmt(),
                        row.curC(), row.xcr(), row.xcrBseDt(), row.cttSno());
            } else {
                bbizgmRepository.save(Bbizgm.builder()
                        .abusMngNo(abusMngNo).sno(row.sno())
                        .gclNm(row.gclNm()).ioeC(row.ioeC()).qty(row.qty())
                        .amt(row.amt()).fcAmt(row.fcAmt()).curC(row.curC())
                        .xcr(row.xcr()).xcrBseDt(row.xcrBseDt()).cttSno(row.cttSno())
                        .build());
            }
        }
        softDeleteMissing(bySno.values(), Bbizgm::getSno, incoming, Bbizgm::delete);
        // 총소요금액 = 요청(=저장 후 활성) 품목 금액 합계 (BITEMM 규칙과 동일하게 amt는 KRW 환산값)
        return rows.stream()
                .map(BizplanDto.ItemRequest::amt)
                .filter(Objects::nonNull)
                .reduce(BigDecimal.ZERO, BigDecimal::add);
    }

    /** 계약 병합 + 저장 후 유효(활성) 계약 SNO 집합 반환 */
    private Set<Integer> mergeContracts(String abusMngNo, List<BizplanDto.ContractRequest> rows) {
        verifyUniqueSnos("계약", rows.stream().map(BizplanDto.ContractRequest::sno).toList());
        Map<Integer, Bbizcm> bySno = bbizcmRepository.findByAbusMngNoOrderBySnoAsc(abusMngNo).stream()
                .collect(Collectors.toMap(Bbizcm::getSno, Function.identity()));
        Set<Integer> incoming = new HashSet<>();
        for (BizplanDto.ContractRequest row : rows) {
            incoming.add(row.sno());
            Bbizcm existing = bySno.get(row.sno());
            if (existing != null) {
                if ("Y".equals(existing.getDelYn())) {
                    existing.restore();
                }
                existing.updateContract(row.cttNm(), row.nowCttManrC(), row.cttTrmMmNbr());
            } else {
                bbizcmRepository.save(Bbizcm.builder()
                        .abusMngNo(abusMngNo).sno(row.sno())
                        .cttNm(row.cttNm()).nowCttManrC(row.nowCttManrC())
                        .cttTrmMmNbr(row.cttTrmMmNbr())
                        .build());
            }
        }
        softDeleteMissing(bySno.values(), Bbizcm::getSno, incoming, Bbizcm::delete);
        return incoming;
    }

    /** 요청에 없는 활성 행 soft delete (이미 삭제된 행은 그대로 둔다) */
    private static <T extends com.kdb.it.domain.entity.BaseEntity> void softDeleteMissing(
            java.util.Collection<T> existing, Function<T, Integer> snoOf,
            Set<Integer> incoming, java.util.function.Consumer<T> deleter) {
        for (T row : existing) {
            boolean active = !"Y".equals(row.getDelYn());
            if (active && !incoming.contains(snoOf.apply(row))) {
                deleter.accept(row);
            }
        }
    }

    /** 상세 응답 조립 (활성 자식 행만, SNO 오름차순) */
    private BizplanDto.Detail toDetail(Bbizpm plan) {
        String abusMngNo = plan.getAbusMngNo();
        List<BizplanDto.Schedule> schedules = bbizsmRepository.findByAbusMngNoOrderBySnoAsc(abusMngNo).stream()
                .filter(r -> !"Y".equals(r.getDelYn()))
                .map(r -> new BizplanDto.Schedule(r.getSno(), r.getDsdCone(), r.getSttDt(), r.getEndDt()))
                .toList();
        List<BizplanDto.Item> items = bbizgmRepository.findByAbusMngNoOrderBySnoAsc(abusMngNo).stream()
                .filter(r -> !"Y".equals(r.getDelYn()))
                .map(r -> new BizplanDto.Item(r.getSno(), r.getGclNm(), r.getIoeC(), r.getQty(),
                        r.getAmt(), r.getFcAmt(), r.getCurC(), r.getXcr(), r.getXcrBseDt(), r.getCttSno()))
                .toList();
        List<BizplanDto.Contract> contracts = bbizcmRepository.findByAbusMngNoOrderBySnoAsc(abusMngNo).stream()
                .filter(r -> !"Y".equals(r.getDelYn()))
                .map(r -> new BizplanDto.Contract(r.getSno(), r.getCttNm(), r.getNowCttManrC(), r.getCttTrmMmNbr()))
                .toList();
        return new BizplanDto.Detail(abusMngNo, plan.getAbusNm(), plan.getBgNo(), plan.getTotRqmAmt(),
                plan.getItPtlEdrtTc(), plan.getRedtConeInf(), currentStatus(abusMngNo),
                schedules, items, contracts);
    }
}
```

```ts
/**
 * ============================================================================
 * [useBizplans] 사업계획 Composable
 * ============================================================================
 * Spring Boot 백엔드의 /api/project/bizplans 엔드포인트와 통신합니다.
 *
 * [제공 기능]
 *  - fetchBizplans : 사업계획 목록 조회 (BPLANA 포함 사업 기준, useApiFetch)
 *  - enterBizplan  : 상세 진입 create-or-get (POST, 미생성 시 생성 + 상태 21)
 *  - fetchBizplan  : 상세 재조회 (GET, $apiFetch — 저장 후 명령형 refresh 용)
 *  - saveBizplan   : 전체 저장 (PUT, 보고서+일정/품목/계약)
 *  - changeStatus  : 완료 전이 (POST /status, 21→29)
 *
 * [주의] $apiFetch 호출 시 절대 URL 필수 (CLAUDE.md §4.3.1)
 * ============================================================================
 */

import type { BizplanDetail, BizplanListItem, BizplanSaveRequest } from '~/types/bizplan';
import { createChangeStatus } from '~/composables/useDocumentStatusApi';

/**
 * 사업계획 Composable 함수
 *
 * @returns 사업계획 관련 API 함수 객체
 */
export const useBizplans = () => {
    /** 백엔드 API 베이스 URL (절대 URL, CLAUDE.md §4.3.1) */
    const config = useRuntimeConfig();
    const API_BASE_URL = `${config.public.apiBase}/api/project/bizplans`;

    /** POST/PUT 요청용 인증된 fetch (plugins/auth.ts에서 provide) */
    const { $apiFetch } = useNuxtApp();

    /**
     * 사업계획 목록 조회 (반응형)
     *
     * @param query - 선택적 쿼리 파라미터
     * @returns useApiFetch 반환값 ({ data, pending, error, refresh })
     */
    const fetchBizplans = (query?: Record<string, string>) => {
        return useApiFetch<BizplanListItem[]>(API_BASE_URL, query ? { query } : {});
    };

    /**
     * 상세 진입 (create-or-get) — 미생성이면 서버가 생성하고 상태 21을 부여합니다.
     *
     * @param abusMngNo - 사업관리번호
     * @returns 사업계획 상세
     */
    const enterBizplan = async (abusMngNo: string): Promise<BizplanDetail> => {
        return await $apiFetch<BizplanDetail>(`${API_BASE_URL}/${abusMngNo}`, {
            method: 'POST',
        });
    };

    /**
     * 상세 재조회 (부수효과 없음, 저장 후 refresh 용 명령형 GET)
     *
     * @param abusMngNo - 사업관리번호
     */
    const fetchBizplan = async (abusMngNo: string): Promise<BizplanDetail> => {
        return await $apiFetch<BizplanDetail>(`${API_BASE_URL}/${abusMngNo}`);
    };

    /**
     * 전체 저장 — 보고서/전결권 + 일정/품목/계약.
     * 완료(29) 상태에서도 반복 저장이 가능합니다(상태 유지).
     *
     * @param abusMngNo - 사업관리번호
     * @param body      - 저장 요청 본문
     */
    const saveBizplan = async (abusMngNo: string, body: BizplanSaveRequest): Promise<undefined> => {
        await $apiFetch<undefined>(`${API_BASE_URL}/${abusMngNo}`, {
            method: 'PUT',
            body,
        });
    };

    /**
     * 상태 전이 — 21(작성중) → 29(작성완료)만 허용
     *
     * @param abusMngNo - 사업관리번호
     * @param stsTc - 목표 상태코드 ('29')
     */
    const changeStatus = createChangeStatus($apiFetch, API_BASE_URL);

    return {
        fetchBizplans,
        enterBizplan,
        fetchBizplan,
        saveBizplan,
        changeStatus,
    };
};
```

```vue
const loadDetail = async (viaEnter = false) => {
    loading.value = true;
    loadError.value = null;

        detail.value = viaEnter ? await enterBizplan(abusMngNo) : await fetchBizplan(abusMngNo);

        loading.value = false;

const reportHtml = ref('');
const itPtlEdrtTc = ref<string | null>(null);

interface EditableRow {
    _localId: number;
    _deleted: boolean;
    sno: number;
}
interface ScheduleRow extends EditableRow {
    dsdCone: string;
    sttDt: string; // YYYYMMDD
    endDt: string; // YYYYMMDD
}
interface ItemRow extends EditableRow {
    gclNm: string;
    ioeC: string | null;
    qty: number | null;
    amt: number | null;
    fcAmt: number | null;
    curC: string;
    xcr: number | null;
    xcrBseDt: string;
    cttSno: number | null;
}
interface ContractRow extends EditableRow {

    nowCttManrC: string | null;
    cttTrmMmNbr: number | null;

const scheduleRows = ref<ScheduleRow[]>([]);
const itemRows = ref<ItemRow[]>([]);
const contractRows = ref<ContractRow[]>([]);

/** 서버 상세 → 편집 행 동기화 (저장/새로고침 후 호출) */
const syncRows = () => {
    const d = detail.value;
    reportHtml.value = d?.redtConeInf ?? '';
    itPtlEdrtTc.value = d?.itPtlEdrtTc ?? null;
    scheduleRows.value = (d?.schedules ?? []).map((r) => ({
        _localId: ++localIdCounter,
        _deleted: false,
        sno: r.sno,
        dsdCone: r.dsdCone ?? '',
        sttDt: r.sttDt ?? '',
        endDt: r.endDt ?? '',
    }));
    itemRows.value = (d?.items ?? []).map((r) => ({
        _localId: ++localIdCounter,
        _deleted: false,
        sno: r.sno,
        gclNm: r.gclNm ?? '',
        ioeC: r.ioeC,
        qty: r.qty,
        amt: r.amt,
        fcAmt: r.fcAmt,
        curC: r.curC ?? 'KRW',
        xcr: r.xcr,
        xcrBseDt: r.xcrBseDt ?? '',
        cttSno: r.cttSno,
    }));
    contractRows.value = (d?.contracts ?? []).map((r) => ({
        _localId: ++localIdCounter,
        _deleted: false,
        sno: r.sno,
        cttNm: r.cttNm ?? '',
        nowCttManrC: r.nowCttManrC,
        cttTrmMmNbr: r.cttTrmMmNbr,
    }));
};

/** 다음 SNO 부여 (해당 그리드의 최대 SNO + 1 — 삭제 표시 행 포함) */
const nextSno = (rows: EditableRow[]) => Math.max(0, ...rows.map((r) => r.sno)) + 1;

const addSchedule = () => {
    scheduleRows.value.push({
        _localId: ++localIdCounter,
        _deleted: false,
        sno: nextSno(scheduleRows.value),
        dsdCone: '',
        sttDt: '',
        endDt: '',
    });
};
const addItem = () => {
    itemRows.value.push({
        _localId: ++localIdCounter,
        _deleted: false,
        sno: nextSno(itemRows.value),
        gclNm: '',
        ioeC: null,
        qty: null,
        amt: null,
        fcAmt: null,
        curC: 'KRW',
        xcr: null,
        xcrBseDt: '',
        cttSno: null,
    });
};
const addContract = () => {
    contractRows.value.push({
        _localId: ++localIdCounter,
        _deleted: false,
        sno: nextSno(contractRows.value),
        cttNm: '',
        nowCttManrC: null,
        cttTrmMmNbr: null,
    });
};

/** 행 삭제 토글 — 저장 시 요청에서 제외되어 서버가 soft delete */
const toggleDelete = (row: EditableRow) => {
    row._deleted = !row._deleted;
};

/** StyledDataTable 삭제행 스타일 */
const rowClass = (row: EditableRow) => (row._deleted ? 'row-deleted' : '');

/** 활성(삭제 표시 제외) 계약 → 품목 계약연결 Select 옵션 */
const contractOptions = computed(() =>
    contractRows.value
        .filter((c) => !c._deleted)
        .map((c) => ({ label: c.cttNm || `계약 #${c.sno}`, value: c.sno })),
);

/** 활성 품목 금액 합계 (화면 표시용 — 저장 시 서버가 동일 규칙으로 재계산) */
const totalAmount = computed(() =>
    itemRows.value
        .filter((r) => !r._deleted)

);

// ============================================================================
// 날짜 헬퍼 — DatePicker(Date) ↔ YYYYMMDD 문자열
// ============================================================================

const ymdToDate = (ymd: string): Date | null => {
    if (!/^\d{8}$/.test(ymd)) return null;
    return new Date(Number(ymd.slice(0, 4)), Number(ymd.slice(4, 6)) - 1, Number(ymd.slice(6, 8)));
};
const dateToYmd = (d: Date | null): string => {
    if (!d) return '';
    const mm = String(d.getMonth() + 1).padStart(2, '0');
    const dd = String(d.getDate()).padStart(2, '0');
    return `${d.getFullYear()}${mm}${dd}`;
};

const saving = ref(false);
const completing = ref(false);
const showCompleteConfirm = ref(false);

/** 저장 요청 본문 조립 — 삭제 표시 행 제외, 빈 문자열은 undefined로 정리 */
const buildPayload = (): BizplanSaveRequest => ({
    redtConeInf: reportHtml.value || undefined,
    itPtlEdrtTc: itPtlEdrtTc.value || undefined,
    schedules: scheduleRows.value
        .filter((r) => !r._deleted)
        .map((r) => ({
            sno: r.sno,
            dsdCone: r.dsdCone || undefined,
            sttDt: r.sttDt || undefined,
            endDt: r.endDt || undefined,
        })),
    items: itemRows.value
        .filter((r) => !r._deleted)
        .map((r) => ({
            sno: r.sno,
            gclNm: r.gclNm || undefined,
            ioeC: r.ioeC || undefined,
            qty: r.qty ?? undefined,
            amt: r.amt ?? undefined,
            fcAmt: r.fcAmt ?? undefined,
            curC: r.curC || undefined,
            xcr: r.xcr ?? undefined,
            xcrBseDt: r.xcrBseDt || undefined,
            cttSno: r.cttSno ?? undefined,
        })),
    contracts: contractRows.value
        .filter((r) => !r._deleted)
        .map((r) => ({
            sno: r.sno,
            cttNm: r.cttNm || undefined,
            nowCttManrC: r.nowCttManrC || undefined,
            cttTrmMmNbr: r.cttTrmMmNbr ?? undefined,

});

/** [저장] — 전체 저장 후 GET으로 재동기화 */

    saving.value = true;
    try {
        await saveBizplan(abusMngNo, buildPayload());

        await loadDetail();

    } catch (e: any) {
        toast.add({ severity: 'error', summary: '저장 실패', detail: e?.data?.message || '사업계획 저장 중 오류가 발생했습니다.', life: 4000 });
    } finally {
        saving.value = false;
    }
};

/** [완료] — 21→29 전이 (완료 후에도 수정 가능 안내) */

    completing.value = true;

        await changeStatus(abusMngNo, BIZPLAN_STATUS.DONE);
        toast.add({ severity: 'success', summary: '작성 완료', detail: '사업계획이 작성완료(29) 처리되었습니다. 이후에도 수정할 수 있습니다.', life: 3000 });
        showCompleteConfirm.value = false;
        await loadDetail();
        await refreshProject();
        // eslint-disable-next-line @typescript-eslint/no-explicit-any
    } catch (e: any) {
        toast.add({ severity: 'error', summary: '완료 처리 실패', detail: e?.data?.message || '완료 처리 중 오류가 발생했습니다.', life: 4000 });
    } finally {
        completing.value = false;
    }
};
```
