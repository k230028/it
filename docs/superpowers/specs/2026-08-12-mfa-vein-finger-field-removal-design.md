# 지정맥 MFA 손가락 선택 항목 제거 설계

## 목적

MFA(추가 인증) 대화상자에서 지정맥 인증 수단을 선택했을 때 표시되는 `인증할 손가락` 선택 항목을 제거한다.

## 범위

- `MfaDialog`에서 손가락 선택 라벨과 선택 컨트롤을 렌더링하지 않는다.
- 화면에서 더 이상 사용하지 않는 손가락 선택 이벤트 처리와 관련 import를 제거한다.
- BioAgent 지정맥 인증 요청은 기존 기본 손가락 값(`10`)을 계속 사용한다.
- `useMfa`의 지정맥 인증 흐름, 서버 API, BioAgent 메시지 규격은 변경하지 않는다.

## 동작

사용자가 지정맥을 선택하면 인증기기 상태와 실행 안내만 확인할 수 있다. 확인 버튼을 누르면 기존과 동일하게 BioAgent 연결 및 인증이 진행되며, 요청의 `fingertype`에는 내부 기본값이 전달된다.

## 헤더와 인증수단 버튼 간격

- 다이얼로그 헤더와 본문 첫 요소인 인증수단 버튼 행 사이에 `1rem`의 세로 여백을 둔다.
- 버튼 행에 개별 여백을 주지 않고 `.mfa-dialog` 본문 컨테이너에 `padding-top: 1rem`을 적용한다.
- 기존 좌우 여백과 본문 요소 사이의 `gap: 1rem`은 유지한다.

## 인증수단 전환 시 크기 유지

- 인증수단 버튼과 남은 시간 아래의 인증별 본문을 하나의 콘텐츠 영역으로 묶는다.
- 콘텐츠 영역 높이는 `clamp(18rem, 45vh, 22rem)`으로 고정하여 같은 화면 크기에서 인증수단을 전환해도 다이얼로그 높이가 바뀌지 않게 한다.
- 인증별 안내, QR, OTP 입력, 에이전트 실행 안내, 오류 문구는 모두 고정 콘텐츠 영역 안에 렌더링한다.
- 콘텐츠가 고정 영역을 초과하면 콘텐츠 영역 내부에서만 세로 스크롤한다.

## 인증수단 아이콘

- 인증수단 버튼의 텍스트 왼쪽에 기존 PrimeIcons 아이콘을 배치한다.
- 지정맥은 `pi-key`, FIDO는 `pi-shield`, 모바일 OTP는 `pi-mobile`을 사용한다.
- 아이콘은 버튼 텍스트와 동일한 색상을 상속하여 선택 상태를 함께 표현한다.
- 아이콘은 장식 요소로 처리하고 버튼의 접근 가능한 이름은 기존 인증수단 이름으로 유지한다.

## 테스트

- 지정맥 화면에도 `mfa-finger-type` 선택 컨트롤이 존재하지 않는지 컴포넌트 테스트로 검증한다.
- 지정맥 외 인증 수단의 기존 렌더링과 BioAgent 기본 손가락 값 전달 테스트가 계속 통과하는지 확인한다.
- 브라우저에서 MFA 대화상자를 열어 헤더와 인증수단 버튼 행 사이에 16px 여백이 보이는지 확인한다.
- 각 인증수단 버튼에 지정된 아이콘 클래스가 렌더링되는지 컴포넌트 테스트로 검증한다.
- 인증수단을 순서대로 전환하며 다이얼로그 높이가 동일한지 브라우저에서 검증한다.

## 비범위

- 손가락 종류 타입, 기본값, composable 공개 인터페이스 제거
- BioAgent 또는 백엔드 지정맥 연계 규격 변경
- MFA 대화상자의 다른 문구나 레이아웃 변경
