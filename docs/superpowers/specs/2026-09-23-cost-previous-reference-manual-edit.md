# 전산업무비 전년도 관리번호 수기 수정 설계

- 적용 화면은 전산업무비 단건 수정 화면이다.
- 기존 `[연결]` 버튼 오른쪽에 `[수정]` 버튼을 둔다.
- `[수정]`을 누르면 관리번호를 직접 입력할 수 있고 `[확인]`으로 검증한다.
- 다른 부서 항목도 전년도 참조 대상으로 허용한다.
- 관리번호가 없으면 `해당 관리번호가 없습니다.`를 표시한다.
- 관리번호는 존재하지만 현재 항목의 직전 연도가 아니면 `직전 연도 관리번호만 연결할 수 있습니다.`를 표시한다.
- 성공 시 관리번호와 전년도 예산을 반영한다.
- 확인되지 않은 입력은 저장할 수 없다.
- 서버도 저장 시 존재 여부와 직전 연도를 다시 검증한다.
- 다른 부서의 전체 상세정보는 노출하지 않고 관리번호·연도·금액·통화만 반환한다.
