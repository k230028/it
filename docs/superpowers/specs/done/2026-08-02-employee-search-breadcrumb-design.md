# 직원 검색 부서 브레드크럼 표시 설계

## 목적

직원 검색 다이얼로그 우측 상단의 부서 브레드크럼이 긴 조직 경로 때문에 두 줄로 표시되는 문제를 줄인다.

## 표시 규칙

- 최상위 level 1 조직 자체를 선택한 경우에는 해당 조직을 브레드크럼에 표시한다.
- level 2 이하의 하위 조직을 선택한 경우에는 경로의 첫 번째 항목인 level 1 조직을 제외한다.
- 조직명 문자열을 비교하지 않고 경로 깊이로 판단하므로 최상위 조직명이 변경되어도 같은 규칙을 적용한다.

예시는 다음과 같다.

- `한국산업은행` 선택: `한국산업은행`
- `전무이사` 선택: `전무이사`
- `하위부서` 선택: `전무이사 > 기획관리부문 > KDB미래전략연구소 > 하위부서`

## 구현

조직 선택과 직원 클릭 이동에서 사용하는 `selectedPath`는 전체 경로를 계속 보관한다. 화면 렌더링에만 사용하는 계산값을 추가하고, 전체 경로 길이가 1이면 원본을 반환하며 2 이상이면 첫 항목을 제외한다.

브레드크럼 항목, 구분자, 현재 항목 강조는 표시용 계산값을 기준으로 렌더링한다. 직원 목록의 빈 상태 판단 등 기존 내부 로직은 전체 `selectedPath`를 계속 사용한다.

## 테스트

- 최상위 조직을 선택하면 level 1 조직명이 표시되는지 검증한다.
- 하위 조직으로 이동하면 level 1 조직명은 표시되지 않고 level 2부터 선택 조직까지 표시되는지 검증한다.
- 마지막 표시 항목의 현재 조직 강조와 기존 직원 선택 동작이 유지되는지 검증한다.

## 완료 조건

- 최상위 조직 자체 선택을 제외한 모든 브레드크럼에서 level 1 항목이 제거된다.
- 조직명 문자열에 의존하지 않는다.
- 관련 컴포넌트 테스트와 프론트 정적 검사가 통과한다.
