## 구현 계약

- 일반 게시판과 댓글의 기존 권한 유지. 화면 버튼 표시와 서버 권한 검증 구분.
- 증감사유는 필수값 아님. UTF-8 바이트로 입력과 저장 검증, 행 변경 추적에 포함.
- 사용자 지정 전결권은 기존 edrtTc 필드 사용. 30~35만 선택 가능하며 표시는 공통코드 명칭 사용.
- 다이얼로그 닫기는 무변경, 저장만 폼 반영. 이후 폼 전체 저장으로 서버 영속화.
- 수동 코드는 재조회·계속사업·금액·품목·코드 옵션 변경에도 자동 계산에서 제외.
- 서버의 기존 전결권 저장 경로가 입력값을 보존하는지 테스트로 확인.
- DB 신규 마이그레이션과 검증 SQL·운영 인계 작성. 운영 적용은 DBA 검토 대상.

## 검증과 산출물

- 권한별 단위·E2E, 한글·영문 200/201바이트 경계, 일괄 저장 후 유지 검증.
- 수동 전결권 선택·취소·저장·자동 계산 방지 및 자동 전결권 기존 동작 회귀 검증.
- 분석/설계서와 테스트결과서는 프로젝트 it-design-doc·it-test-doc 양식 사용.
- 실행하지 못한 검증은 미실시·미확인으로 기록. 요청자 성명은 미기재.
- 2026-09-17 사용자 지시에 따라 관련 변경을 각 저장소 main에 커밋·푸시한다.
