# FE-94 일반 사용자 화면의 행번 비표시

- 요청자: K230028. 일반 화면에서 이름(행번)은 이름만, 행번 열 삭제, 이름이 없으면 빈칸.
- 공통 헤더·직원 정보·검색·자동완성, 사업/비용 담당자, 결재선, 충돌 비교, 게시판·예산·문서 이름 폴백 및 Excel/PDF 표시가 대상.
- 관리자 전용 /admin, /info/plan, 협의회 개최준비의 공통 컴포넌트는 기존 표시를 유지한다. 역할 자체가 아니라 화면 문맥으로 판정한다.
- ENO·USID·CGPR_ID 및 결재선 id는 삭제하거나 변경하지 않는다. 조회·선택·저장·권한·결재·메신저 처리용 값은 보존한다.
- 이름 응답이 없는 경우 행번으로 대체하지 않고 빈칸. 사전협의 수정자 이름은 현재 API에 없으므로 빈칸 처리한다.
- 사용자 확정: 전산업무비 업로드 양식의 담당자사번 열 및 기존 입력·처리 방식 유지. 다운로드 데이터와 오류 메시지는 비표시 대상.
- 검증: 관리자/일반 화면 경계, 이름 누락, 선택 시 내부 id 보존, 다운로드 행번 제거, 관련 단위·전체 검사·브라우저 테스트.
