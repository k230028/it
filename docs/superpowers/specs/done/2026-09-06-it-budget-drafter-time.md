# 전산예산 기안자 결재 시각 표시 설계

## 목표

전산예산 신청서 PDF 결재선의 기안자 결재일자 아래에 실제 상신 시각을 `HH:mm:ss` 형식으로 표시한다.

## 계약

- 상신 시 생성하는 초 단위 `LocalDateTime`을 기안자 스냅샷의 `date`에 저장한다.
- 미리보기와 기존 v2 스냅샷은 기안 시각이 없을 수 있으므로 `date`를 선택값으로 취급한다.
- 프론트엔드는 기안자 `date`가 있으면 기존 결재일시 셀 렌더러에 전달한다.
- PDF 상단의 `신청일자`는 기존처럼 날짜만 표시한다.
- 시각이 없는 과거 문서에는 임의의 `00:00:00`을 표시하지 않는다.

## 검증

- 백엔드 상신 테스트에서 저장 JSON의 `approvalLine.requester.date`가 초 단위 시각인지 확인한다.
- 프론트 스냅샷 파싱 테스트에서 기안자 시각 전달과 과거 스냅샷 호환성을 확인한다.
- PDF 구조 테스트에서 기안자 셀이 `YYYY-MM-DD`와 `HH:mm:ss` 두 줄인지 확인한다.
