# 전산업무비 금융정보단말기 전년도 불러오기 설계

## 목표

전산업무비에 수기로 입력한 금융정보단말기 상세를 같은 전산업무비 개정본에 저장하고, 전년도 불러오기 시 부모와 상세 목록을 신규 수정 가능 행으로 함께 복제한다.

## 저장 계약

- 저장된 전산업무비에서 금융정보단말기를 "지금 작성"하면 별도 BCOSTM을 생성하지 않는다.
- 정확한 부모 `(BG_NO, BG_SNO)`에 BTERMM 목록을 치환 저장한다.
- 서버는 부모를 잠근 뒤 예산기간, 소유권, 결재상태, 동시성 스탬프를 검증한다.
- 서버는 단말기 원화 환산 합계를 BCOSTM 금액에 반영하고 `TMN_YN='Y'`, `CUR_C='KRW'`, `FC_AMT=NULL`로 맞춘다.
- 단말기 식별자가 없는 행은 신규 채번하고, 요청에서 빠진 기존 활성 행은 논리 삭제한다.

## 전년도 복제 계약

- 부모의 관리번호·순번·결재정보·동시성 정보·감사/최종 여부는 신규 행에 승계하지 않는다.
- 단말기 업무 필드는 깊은 복사하되 `tmnMngNo`, `sno`는 승계하지 않는다.
- 대상 예산연도, 계속 사업구분, 전년도 참조번호, 최초지급일 +1년은 기존 규칙을 유지한다.
- `_status='new'`인 로컬 행은 원본의 결재 상태와 무관하게 수정 가능하다.

## 기존 자료

과거 `linked-costs` 경로로 생성된 별도 BCOSTM에는 원래 부모를 식별할 영속 연결키가 없다. 이번 변경은 신규 저장과 이후 전년도 복사를 바로잡으며, 기존 분리 자료의 자동 재연결은 범위에 포함하지 않는다.
